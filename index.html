Design your roof, your way

Sportify arranges sports, activities, and garden zones on a shared roof, automatically checking the same rules a real facility planner would. Site, Sport, Garden, Combine, Analysis, Compare and Data all live in the rail on the left — here's the order they're meant to be used in.

How it thinks

Three layout philosophies Sportify can work from — whichever one you build toward, the same rules underneath decide if it's actually usable.

Define a base module and every piece aligns to it — orderly, predictable, easy to extend. Combine's rule-based auto-arrange already produces a tidy, grid-like default layout today.

Circulation branches recursively, like a maze, subdividing the roof into progressively smaller zones instead of one central corridor. The circulation engine's grid + pathfinding core is already built toward this.

Draw the boundary by hand — zones adapt to a freeform shape instead of a rectangle, the way a real garden follows the land rather than a grid. Combine already renders an arbitrary polygon boundary when one is imported from Revit; hand-drawing one yourself is the natural next step.

The rules every layout follows

Whichever philosophy a layout comes from, four rules decide whether it's actually usable — the same ones Combine's auto-arrange and suggested spots already respect (see them live, with the same wording, in Combine's Rules step).

Clearance

Minimum gap kept between any two pieces, so there's room to walk between them.

Boundary setback

Minimum gap kept between any piece and the roof edge — a safety margin around the perimeter.

Circulation width

How wide a gap must be to count as a real walkway — narrower gaps don't connect a piece to an entrance, even if nothing overlaps.

Entry points

Every piece needs a walkable path back to at least one entrance.

These four rules aren't one-size-fits-all. Sportify also looks at how much you've actually programmed onto the roof — as the total footprint grows, it recommends wider circulation and more entrances, the same way a real building code scales egress with occupant load. It's a suggestion, not a forced override — the planner still decides. You'll see it live, with an Apply button, in Combine's Rules step once a few pieces are placed.

Min. entry points

How many entrances the layout needs. Every piece must have a walkable path back to at least one.

Quiet buffer (m)

Minimum gap kept between a wellness/garden zone and a loud court or activity — separate from clearance, which only prevents overlap.
